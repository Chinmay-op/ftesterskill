# Persona-Driven Journeys

Domain 11 of f-tester moves away from robotic traversal and introduces **Persona-Driven User Journeys**.

By defining Personas (e.g., "Impatient mobile user", "Error-prone user"), f-tester executes paths through your app with specific limitations in mind.

## What is tracked:
- Task Success vs Failure
- Hesitation map (where did the user pause?)
- Friction scoring (how hard was it to achieve the goal?)
- Abandonment risk
