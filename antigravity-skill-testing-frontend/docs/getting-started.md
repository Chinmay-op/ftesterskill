# Getting Started

f-tester is a dual-purpose frontend testing tool:
1. **CLI Tool**: Run UI tests, evaluate UX, and check for leakages manually.
2. **AI Skill**: Teach your AI agent how to perform human-like UX audits.

## Installation

Run it via npx without installing:
```bash
npx f-tester --help
```

## Basic Usage

1. **Build your project**:
```bash
npm run build
```

2. **Run tests**:
```bash
npx f-tester run-all
```
