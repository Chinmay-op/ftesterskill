# UX Heuristic Evaluation

Domain 12 evaluates all UI findings against Nielsen's 10 Usability Heuristics.

Instead of just reporting "Button is missing label", f-tester categorizes it as a **Feedback** or **Clarity** issue and evaluates the cognitive load on the user.

## Core Clusters Checked
- Clarity (H2, H6, H8)
- Feedback (H1, H9)
- Control (H3, H5, H7)
- Consistency (H4)
- Trust (H1, H9, H10)
